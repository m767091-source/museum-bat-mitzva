המוזיאון הנעול — חוויית אוצר, בית ספר אמיר
גרסה 18.11.2026

כלול: 5 חדרי פעילות, סרטוני המקור של גולדה / לינוי / עדה (ללא עריכה), מכתבים מומחזים של חנה ונעמי, כספת, כרטיסי ערכים וסיום עם נר.

בדיקות שרת שבוצעו: 36 משתמשות מדומות, מניעת משתתפת 37, העברת מצב דרך WebSocket, הרשאות ושירות הקבצים. בדיקה גרפית מלאה בדפדפן ובדיקת 36 טאבלטים אמיתיים עדיין חסרות.

אין עדיין קישור ציבורי. פרסום Render דורש מאגר Git המחובר לחשבון; Render עצמו מחובר כעת.

הערה חשובה: בתוכנית Render Free מצב השרת עשוי להתאפס בפריסה/הפעלה מחדש. אין להסתמך על שמירת תגובות בין הפעלות שונות ללא אחסון נתונים קבוע. יש לבצע חזרה גנרלית על הרשת הבית-ספרית לפני האירוע וליצור חדר חדש בתחילת הפעילות.

לבדיקה מקומית: pip install -r requirements.txt ; python server.py ; פותחים במחשב http://localhost:8080
