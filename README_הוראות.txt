המוזיאון הנעול – בית ספר אמיר – גרסת משחק עם 36 תלמידות
=========================================================
מה נכלל?
* 5 אולמות: גולדה מאיר, לינוי אשרם, חנה סנש, עדה יונת, נעמי שמר.
* 3 סרטונים מקוריים שהועלו, במקומם המתאים. אלה אינם הגרסאות הערוכות!
* 2 מכתבים מומחזים (חנה סנש ונעמי שמר).
* 7 צוותים, עד 6 תלמידות לצוות, 42 מקומות בסך הכול.
* מסך מנחה, קוד כניסה, קישור QR, משימות, תשובות בזמן אמת, כספת 147 וקיר ערכים.
* ההתקדמות מתבצעת רק בידי המנחה. כל בת עונה בטלפון.

מה נבדק?
* מבחן אוטומטי: כניסה של 36 תלמידות ל-7 צוותים — עבר.
* גבול 6 תלמידות בקבוצה וחסימת כניסה לקבוצה מלאה — עבר.
* תשובה שנשמרת, חסימת פקודות מנחה ממשתתפת — עבר.
* הודעות עדכון בין שני לקוחות WebSocket נפרדים — עבר.
* תקינות קוד ה-JavaScript — עבר.
* בדיקת דפדפן גרפית מלאה ובדיקת 36 מכשירי טלפון פיזיים — טרם התבצעו.

הפעלה על מחשב
1. התקינו Python 3.10 ומעלה ממקור רשמי.
2. פתחו Terminal / PowerShell בתוך תיקיית הקבצים.
3. הפעלו: pip install -r requirements.txt
4. הפעילו: python server.py
5. במחשב: http://localhost:8080
6. בטלפונים: יש לפתוח http://כתובת-IP-של-המחשב:8080 (כולם באותה רשת Wi-Fi,
   יש לוודא שהרשת אינה מבודדת מכשירים ושחומת האש מתירה גישה לפורט 8080).
7. הכתובת שתוצג על מסך המנחה חייבת להיות כתובת שניתן לפתוח מהטלפונים.
   אם המנחה משתמשת ב-localhost, הקישור שייווצר לא יתאים לטלפונים!
   לכן מומלץ להיכנס למסך המנחה דרך כתובת ה-IP של המחשב מלכתחילה.
8. לוחצים 'פתיחת חדר כמנחה'; מקרינים QR או מעבירים קישור לטלפונים.

הפעלה באינטרנט מחוץ לרשת
* יש לפרסם את הפרויקט בשרת Python שתומך WebSocket ו-HTTPS (לדוגמה Render).
* הפעלה: pip install -r requirements.txt ; python server.py
* השרת משתמש במשתנה PORT המסופק בידי הספק.
* יש לדאוג לאחסון קבוע לקובץ rooms.json על השרת. ללא אחסון קבוע,
  איפוס/הפצה מחדש עשויים למחוק חדרים ותשובות. אין להעלות קובץ זה לרשת ציבורית.
* האתר עדיין אינו מפורסם, ולכן אין כרגע קישור ציבורי מוכן לתלמידות.

לפני יום הפעילות
* בדקו חיבור לפחות שלושה טלפונים שונים והקרנה, רצוי על אותה רשת שבה ישתמשו בכיתה.
* בצעו ניסיון עומס עם 36 טלפונים או בקשו מצוות המחשוב בבית הספר לבצע בדיקת עומס מקומית.
* בדקו שקול הסרטונים נשמע ברמקולים ושכל הסרטונים נפתחים.
* בקשו להזין רק שם פרטי, ללא מידע אישי רגיש.
* כדי לסגור את השרת המקומי השתמשו ב-Ctrl+C; פתחו מחדש את החדר באותו דפדפן.
* הגדרות חומת אש/גישה לרשת וטיפול במידע תלמידות חייבות להיות מאושרות על ידי בית הספר.

חשוב: במקרה של שינוי טקסט במכתב, זכרו שזהו טקסט מומחז שנכתב עבור הפעילות,
ולא מכתב היסטורי אותנטי. הסרטונים המקוריים נוצרו לפני עריכת סנכרון השפתיים.
